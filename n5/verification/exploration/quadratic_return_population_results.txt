POST-HIGH QUADRATIC-RETURN DISCOVERY SNAPSHOT
============================================

Status
------

This is a deterministic discovery/regression record, not a premise of the
manuscript or Lean development.  It records the counterexample that forced
the repeated capacity-restart argument to be withdrawn and the exact
fixed-state checks used to design its replacement.

Population scan
---------------

Command:

  python3 n5/verification/exploration/quadratic_return_population_probe.py --all-planes

Summary:

  populated quotient classes modulo the 9-dimensional Hankel target: 171901
  rational same-plane choices checked:                              35
  choices admitting an unpopulated return:                          15
  simultaneous S3 orbit keys:                                      (0,1),
                                                                    (1,1),
                                                                    (1,2),
                                                                    (1,3)

For every reported witness the program asserts, rather than merely prints,
that the two products have identical nonzero cubic/quartic high part, their
difference has zero cubic and quartic parts, and the returned quotient class
has minimum alternating rank 4 over all Hankel-target translates.  Thus no
translate of that returned class is decomposable.

Canonical witness
-----------------

Let r0 = a0*b0 and start from Aff + <r0,r1,rinf>.  The products

  g = (a2 + b2) * (a2 + r0)
  h = (a2 + b2 + b0) * (a2 + a0 + r0)

have the same nonzero cubic part.  Their sum z = g + h is quadratic.  The
canonical quotient bitset printed by the coordinate reducer is 8194, and
the minimum alternating rank of z+t over all t in the Hankel target is 4.

Exact fixed-state checks for this witness
-----------------------------------------

The state Aff + <r0,r1,rinf,g,h> has dimension 16, target rank 3, and total
defect 2.  The multiplication-map probe finds no target-tight gate from this
state before the final defect birth.

After fixing the next gate as the final defect birth, the shared-solver flag
scan gives exactly the following possibilities in its canonical missing-
target quotient coordinates:

  one target row:  1, 2, 3, 18, 36, 42, 54, 63

  two target rows: (1,2), (2,1), (3,1),
                   (18,36), (36,18), (54,18)

All 90 canonical third-row extensions of those six two-row flags are UNSAT.
Five cases that exceeded the initial ten-second per-flag limit were rerun
individually and also returned UNSAT:

  (18,36,2), (18,36,3), (36,18,2), (36,18,3), (54,18,2)

Consequently this one fixed block admits at most two target rows after the
last defect birth.  The statement is exact for the displayed state, but the
universal manuscript repair still requires a parameterized algebraic return
theorem; this transcript must not be cited as that proof.

Additional orbit representatives
--------------------------------

The first counterexample in each of the four rational-plane S3 orbit types
(0,1), (1,1), (1,2), and (1,3) gives a dimension-16 state of target rank 3.
The exact multiplication-map probe finds no target-tight extension from any
of those four states before the last defect birth.

For the hardest `(0,1)` representative, granting all eight target directions
of the first-order envelope still leaves target rank eight and produces no
target-tight one-gate extension.  This is the fixed-state diagnostic behind
the algebraic two-wedge-section target-intersection lemma; it is not a
substitute for the remaining universal feedback-sterility argument.

After one last defect birth, the (1,2) and (1,3) representatives have six
possible first target rows:

  1, 18, 36, 42, 54, 63.

For the (1,2) representative, only (18,36), (36,18), and (54,18) survive as
ordered two-row flags, and all 45 canonical third-row extensions are UNSAT.
The four cases that exceeded the initial ten-second bound were rerun in
isolation and returned UNSAT.  The (1,3) two-row census is identical; its
third-row census was not rerun because this remains discovery evidence.

One-defect return representatives
---------------------------------

The population probe also has `--base pstar` and `--base e1r0` modes.  They
test the stronger restart obstruction appropriate above an old populated
defect line: a new return is reported only when neither its quotient class
nor its translate by the old defect point is populated.

Both canonical one-defect capacities admit such returns.  For the first
reported degree-two-place and rational-place witnesses, the resulting states
have respectively

  target rank 5, dimension 19; and
  target rank 4, dimension 18.

In each state the total defect is already 3.  The exact multiplication-map
probe finds no target-tight one-gate extension from either state.  A separate
normalized-flag SAT check also excludes four independent target gates from
the degree-two-place witness.  The corresponding five-target SAT run for the
rational witness reached its three-minute diagnostic limit; the exact
one-step multiplication-map result is the useful observation here.

These are fixed representatives only.  They motivate a saturated quadratic-
section lemma and do not establish its required universal classification.

Bounded returned-class diagnostic
---------------------------------

Command:

  python3 n5/verification/exploration/quadratic_return_class_sample.py

The scan retained the first 64 distinct unpopulated returned quotient classes
for each of the four simultaneous rational factor-pair types `(0,1)`, `(1,1)`,
`(1,2)`, and `(1,3)`.  Thus the four fixed sections, even after their six
rational-place symmetry images, cannot exhaust the returns.  For every one
of the 256 first-order target translates of every retained class, the target
exterior kernel happened to be zero.  The printed result was

  uniform_kernel_survives_bounded_sample

This refutes the former fixed-section orbit interface.  The sample was biased
and did not justify a uniform parameterized replacement: the later exact
`quadratic_return_kernel_counterexample.py` exhibits an unpopulated returned
section with nonzero rational annihilator.  The valid section-only conclusion
is therefore the zero-or-rational classification proved in Lean.

The counterexample's actual history was then restored with
`quadratic_return_feedback_probe.py`.  Keeping its born high representative
and allowing its full returned quadratic correction space, none of the 2,048
affine-plus-`r0` feedback factors reaches the missing target coset.  This is
exact for that witness but only motivates, rather than proves, the needed
history-sensitive return theorem.
